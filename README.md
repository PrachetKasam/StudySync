# StudySync

StudySync is a full-stack student academic dashboard.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express.js
- REST API

### Database
- PostgreSQL
- Prisma

### Authentication
- JWT
- bcrypt

## Project Structure

- `client/` — React frontend
- `server/` — Express backend
